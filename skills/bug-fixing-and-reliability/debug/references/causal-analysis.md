# Root Cause Analysis Checklist

Apply selectively to the task and available evidence.

## Causal distinctions

| Element | Meaning |
| --- | --- |
| Symptom | Observable undesirable outcome. |
| Trigger | Condition that initiates a failure sequence. |
| Mechanism | How the failure propagates to the outcome. |
| Contributing factor | Condition that increases likelihood or impact. |
| Systemic weakness | Missing or ineffective control that permits recurrence. |

## Evidence review

- Associate each causal link with observations, tests, or documented contracts.
- Consider alternative explanations and counterexamples; do not infer causation from chronology alone.
- Use repeated why questions or causal diagrams only as aids, not proof.
- Distinguish prevention, detection, mitigation and recovery actions.
- Define how each action will be verified and whether it addresses cause or impact.
