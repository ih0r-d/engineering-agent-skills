# Skill evaluation cases

Maintain small prompts and expected outcomes here. A useful evaluation distinguishes correct activation from false positives and checks that reviews stay read-only, fixes remain scoped, and the agent does not introduce unnecessary abstractions.

Initial scenarios to add:
- Java: a genuinely ignored return value versus an intentionally discarded value.
- Java: duplicated business logic versus intentionally repeated boundary validation.
- Documentation: a consumer quick start versus internal lifecycle reference.
- Release: preparation is allowed; publishing and pushing require explicit authorization.
- Shell: unsafe variable expansion versus a correctly quoted expression.
